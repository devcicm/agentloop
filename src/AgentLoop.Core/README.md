# AgentLoop.Core

Biblioteca net9.0; referencia solamente Kernel. Contiene contratos estrictos,
estado de proyectos, conocimiento por artefacto, presupuesto de contexto y puertos de validadores.
No referencia el host, proveedor, transporte, Docker o un ejercicio de negocio.

Namespaces publicos conservados por compatibilidad. El host admite datos y
recursos, inyecta servicios, publica eventos y persiste snapshots.
